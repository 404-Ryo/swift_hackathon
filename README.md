## 💡 私たちが作ったもの

現代の連絡ツールの LINE などは機能が複雑で、高齢者などには使いづらいことに注目しました。

イメージは **LINE のシンプル版**。

- 📞 電話と 💬 トーク機能 **だけ** に絞る
- 下のタブバーもなくす
- アイコンも文字も **大きく**
- とにかく **迷わず使える UI** を目指す

### デザインの方針

Apple Human Interface Guidelines を参考に設計しました。
Android の UI は平面的ですが、iOS は立体感があってなめらか。その良さをちゃんと活かしたデザインにしています。

### こだわりポイント：オンボーディング

アプリを入れても、最初の「連絡先を登録する」が高齢者には一番のハードル。
そこで **端末同士を近づけるだけで連絡先交換できる仕組み** を入れました。
（家族や友人に会ったときに、その場でサッと追加できる）

この**「誰でも使いやすい設計」と「オンボーディング体験」が評価され、サイボウズ特別賞をいただきました。**

## ✨ 主な機能

| 画面 | できること |
|---|---|
| **れんらくさき一覧** | 登録した人を大きなアイコンで表示。初回は TipKit で「ここを押してください」とガイド |
| **連絡先の詳細** | 「トーク」「でんわ」の 2 つの大きなボタンだけ |
| **連絡先を交換** | iPhone を近づけて、近くにいる人と双方向で連絡先を交換 |

---

## 🛠 技術スタック

- **SwiftUI** — 宣言的 UI
- **MultipeerConnectivity** — 端末間の連絡先交換（Wi-Fi / Bluetooth 経由）
- **TipKit** — 初回利用時のオンボーディングヒント
- **Combine** — 交換状態の監視

### アーキテクチャ概要

```
ContactListView         ← 連絡先一覧（エントリーポイント）
  ├─ ContactRow         ← 1 行分の表示
  ├─ ContactDetailView  ← トーク / でんわ
  └─ ContactExchangeView
        └─ NearbyContactManager  ← MultipeerConnectivity のラッパー
```

`NearbyContactManager` は `MCSession` / `MCNearbyServiceAdvertiser` / `MCNearbyServiceBrowser` の 3 つを束ねて、UI 側には `ExchangePhase`（idle / searching / connecting / received / failed）というシンプルな状態だけを公開しています。

## 📱 動作環境

- iOS 17.0 以上（TipKit のため）
- Xcode 15 以上
- 実機 2 台（交換機能の動作確認用）

`Info.plist` に以下のキーが必要です：

- `NSLocalNetworkUsageDescription`
- `NSBonjourServices` に `_renraku-swap._tcp` と `_renraku-swap._udp`

---

## 🏃 使い方

1. Xcode でプロジェクトを開く
2. 実機を選択してビルド＆実行
3. 連絡先を交換するには、相手も同じアプリを開いた状態で「連絡先を交換」をタップ
4. 自分の「なまえ」と「続柄」を入力 → 「近くの人を探す」
5. 見つかった相手をタップ → 双方向で自動的に交換完了
